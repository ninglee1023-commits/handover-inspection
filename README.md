# 竣工驗收記錄 (handover-inspection)

離線 iPad 網頁程式：圖紙上點選位置 → 拍照 → 標記箭頭／圈選 → 自動帶出座／層／房間／Grid → 導出 Word 報告。

- 純靜態網頁，放上 GitHub Pages 即可使用；首次開啟後可離線。
- 資料儲存在 iPad Safari 的 IndexedDB，請「加入主畫面」並定期備份（完整、只限新增記錄，或按驗收批次每次驗收一個 ZIP）。
- 設定只填檢查人員名字，記錄編號以名字開頭（陳大文-001）。匯入同事的備份時，每個批次自成一個「名字-批次名稱」的批次（同名自動加（2）），不會自動合併；看過後在「驗收批次 → 合併批次」勾選多個批次，輸入新名稱合併，一次出報告。
- 函式庫：pdf.js 3.11.174、docx 8.5.0（已放在 lib/，不需外部 CDN）。
- 兩套圖紙：頂部「建築｜渠務」切換。建築 GBP（gbp/plans.pdf + gbp/mapping.json）及渠務圖（gbp/drainage.pdf 第 8–14、16–24 頁 + gbp/drainage-mapping.json）各自有圖紙清單、驗收批次、編號和報告。渠務圖包第一次切換時下載（約 36 MB）。
- 建築 gbp/plans.pdf：第 1–7 頁為 14th GBP Amd Draft（2026-10-28）的 B3–3/F 平面（3/F 一張包括 T1、T2、T3、T5），第 8–14 頁沿用 13th Amd，第 15–16 頁為 14th Draft 平台立面 E1–E16，第 17–21 頁為 13th Amd 塔樓立面（A/GBP/25–28，Elevation 5–18；13th 的平台立面 A/GBP/21 與 14th Draft 第 15 頁相同，只用後者，原檔抽頁在 gbp/src/gbp13_elevations.pdf）。換頁的圖紙保留原 id，mapping 內的 `xf` 把舊圖上的記錄位置自動搬到新圖（記錄以 `pf` 標記所屬版本，匯入舊備份或舊相片時一樣會轉換）。
- 建築圖紙清單分「平面圖／立面圖」（渠務不設立面）。建築立面（E1–E16）以 `lv` 樓層線取代樓層選擇：點選位置下方最近的樓層線就是該層；軸線（gx）取自立面上的軸線圈，立面編號記在區域欄。塔樓立面（3/F 以上）另有單位格：由立面與平面共用的軸線求出比例及位移（平面 1:100 → 立面 1:200，忽略拐線偏移的軸線圈），再從觀看方向對平面單位範圍投射，最先碰到的單位就是該段外牆的 flat；每個樓層段（3/F、標準層、T5 5–17/F 及 18–30/F）各自計算。
